# Remote controlled car

This repository contains the code and models for a toy remote controlled car.
The chassis is 3D printed, and the car is powered by a Lego Power Functions
motor controlled with an Arduino and a L293D motor driver.

## Tools

The firmware is developed using Arduino IDE. The 3D models are developed using 
OpenSCAD.

The firmware is targeted and has been tested on Arduino Uno, but modifications
may be required to run it on other Arduino or Arduino compatible boards.
